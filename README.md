# Offer Page Starter

A single-page offer site for a coach or consultant. Headline, who it's for, how the work runs, a plain-language promise, and one "Book a call" button.

This copy is framed around 12-week one-on-one coaching, which is the likely first offer. Edit it if you take a different path.

## Use it

There is no build step.

```
npx --yes serve .
```

Or open `index.html` in a browser. Edit the copy and swap `https://calendly.com/YOUR-PERSONAL-LINK` for your real calendar. Add your name in the header and the title tag. Then deploy the folder to any static host (Cloudflare Pages, Netlify, GitHub Pages).

## Copy rules baked in

- One offer, one call to action
- No countdown timers or fake scarcity
- No income claims you can't back up
